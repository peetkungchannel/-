เว็บไซต์ “ขอเพลงกันเถอะ” — แยกเป็น 2 หน้า

ไฟล์:
- index.html : หน้าคิวเพลงและแบบฟอร์มขอเพลง
- admin.html : หน้าระบบแอดมินแยกต่างหาก
- style.css : รูปแบบหน้าตา ใช้ร่วมกันทั้ง 2 หน้า
- queue.js : การส่งคำขอและแสดงคิว
- admin.js : การจัดการสถานะคำขอ และปุ่มลบคำขอ (เฉพาะหน้าระบบแอดมิน)

คิวเพลงเริ่มต้นว่างเปล่า ไม่มีเพลงตัวอย่าง
ผู้ขอเพลงต้องกรอกชื่อผู้ใช้ ชื่อเพลง และชื่อศิลปิน โดยชื่อผู้ใช้จะแสดงในหน้าคิวและหน้าแอดมิน

วิธีเปิด:
1. แตกไฟล์ ZIP
2. เปิด index.html เพื่อเข้าหน้าคิวเพลง
3. เปิด admin.html เพื่อเข้าหน้าแอดมิน
4. ส่งคำขอเพลงจากหน้า index.html แล้วดูรายการในหน้า admin.html
5. ในหน้า admin.html กดปุ่ม 🗑 เพื่อลบคำขอ (มีหน้าต่างถามยืนยันก่อนลบ)

หมายเหตุ:
ข้อมูลใช้ localStorage ในเบราว์เซอร์ จึงเป็นเดโมสำหรับทดสอบในเครื่องเดียวกัน
การเปิดไฟล์ HTML โดยตรงอาจทำให้การแชร์ localStorage ระหว่างสองหน้าแตกต่างกันตามเบราว์เซอร์
ถ้าต้องการทดสอบให้เสถียร ให้เปิดโฟลเดอร์ผ่าน local web server
ถ้าต้องการให้ผู้ใช้หลายเครื่องเห็นข้อมูลร่วมกัน ต้องเพิ่มฐานข้อมูลและระบบล็อกอิน/โฮสต์
